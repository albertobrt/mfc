Dépose ici les logos des partenaires au format PNG (fond transparent de préférence) :
partenaire-1.png, partenaire-2.png, partenaire-3.png, partenaire-4.png, partenaire-5.png, partenaire-6.png
Le site les affichera automatiquement dans le bandeau qui défile.
Pour ajouter plus de partenaires, duplique un bloc <div class="partner-logo">...</div> dans index.html
et ajoute le fichier correspondant ici.
